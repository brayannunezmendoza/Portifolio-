# Portifolio-
Apresentação de informações básicas do desenvolvedor para o público

Oque será mostrado?
    - Nome
    - Foto de perfil
    - Aréa de atuação e/ou desejadas
    - Breve descrição
    - Experiências
    - Projetos desenvolvidos

Como o local de apresentação será?
    - Foto de perfil estilo redondo
    - Nome abaixo da foto
    - Aréa de atuação e/ou desejada abaixo do nome
    Será centralizado no meio da pagina horizontalmente

Como será o local textual?
    - Descrição centralizada e resumida

Como será os projetos desenvolvidos?
    - Estilo carrocel com uma imagem ilustratica do projeto e resumo do projeto abaixo
    - Cada projeto será linkado a um repositorio ou a uma página a dependeter das necessidades.

Pagina
    - Terá uma barra de navegação na parte superior e fixado
    - será uma página
    
Animções
    - Movimentação do carrocel de projetos
    - Alteração do tamanho dos link e projetos ao terem o mouse encima
